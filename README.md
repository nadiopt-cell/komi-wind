# Ветер × рельеф × лес

**#30DayMapChallenge 2026 · Day 13 · Interactions**
Республика Коми · ветровалы 1984–2026 в рельефе, лесах и на охраняемых территориях.

## Интерактивная карта

```bash
# из корня проекта
python -m http.server 8000 --directory web
# затем открыть http://127.0.0.1:8000/
```

Или просто запустить `start_server.bat` — он поднимет сервер и откроет браузер.

> Открывать `web/index.html` двойным щелчком (file://) нельзя: браузер заблокирует загрузку GeoJSON. Нужен любой статический сервер.

**Что умеет:**
- 7 переключателей слоёв: рельеф / породный состав / ООПТ / реки / ветровалы / направления ветра / подписи;
- галочки по каждому 5-летнему периоду: снимаешь — исчезают и полигоны, и стрелки этого периода;
- клик по ветровалу — попап: год, тип события, площадь, направление, длина следа, дата;
- при наведении полигон подсвечивается;
- при отдалении ветровалы показаны кругами (размер ≈ площадь), при приближении — реальными полигонами;
- адаптивная вёрстка: на телефоне панель слоёв уезжает в нижний лист.

Все данные и шрифты лежат локально — интернет не нужен, кроме первого рендера карты в браузере.

## Картографические решения

**Проекция.** Равновеликая Альберса, `lon_0 = 54°E`, `lat_1 = 58°`, `lat_2 = 68°`. Для интерактива — Web Mercator, растры пересчитаны с поправкой масштаба при расчёте отмывки.

**Стрелки ветра.** Для каждого ветровала направление берётся из поля `direction`
(диапазон `WSW-ENE` читается как «от WSW к ENE»). Строится вектор вдоль основного
направления: хвост — снаружи полигона с наветренной стороны, острие — внутри, у
подветренного края. Стрелка окрашена в цвет своего 5-летнего периода — по ней сразу
видно, к какому полигону она относится. Длина: 6 + 2,6·√(площадь, га) км,
ограничение 10–42 км.

**Периоды.** Девять полных пятилеток 1980–2024 и незавершённый последний интервал
«2025 →» (данные по июль 2026). Последовательная шкала от песочного к тёмно-сливовому:
чем свежее событие, тем темнее.

**Породный состав.** Классы Copernicus Forest Type: `1 ENF` и `3 DNF` — хвойные,
`5 mixed` — смешанные, `4 DBF` — лиственные; `0` и `255` прозрачны.

## Ключевые цифры

- 401 событие, 53 279 га повреждённого леса (1984–2026)
- длина стрелки: 6 + 2,6·√(площадь, га) км, ограничение 10–42 км
- 20 % площади — в границах ООПТ
- 67 % потоков приходят с запада и юго-запада
- медианная высота — 178 м; 69 % площади — в полосе 100–200 м
- крупнейший ветровал — 6 221 га (2009, Троицко-Печорский район)
